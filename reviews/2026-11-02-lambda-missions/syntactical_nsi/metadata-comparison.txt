## Types and Constructors (`Ty`, `Ty.bin`, `Ty.lolliMany`, `Var`, `Constructor`, `Constructor.ty`)

**Finite types (`Ty`).** The inductive type of types is generated freely by six constructors:
$$\rho, \tau ::= \diamond \mid \mathsf{B} \mid \tau \multimap \rho \mid \tau \otimes \rho \mid \tau \times \rho \mid \mathsf{L}(\tau).$$
The abbreviation $\mathsf{bin}$ (`Ty.bin`) denotes the list-of-booleans type $\mathsf{L}(\mathsf{B})$. For a finite list of argument types $[\tau_1, \dots, \tau_n]$ and a target type $\rho$, the iterated linear function type (`Ty.lolliMany`) is defined recursively by right-associative folding:
$$\mathrm{lolliMany}([], \rho) = \rho, \qquad \mathrm{lolliMany}(\tau :: \vec{\tau}, \rho) = \tau \multimap \mathrm{lolliMany}(\vec{\tau}, \rho).$$

**Typed variables (`Var`).** A variable $x$ is a pair $(\mathrm{id}(x), \mathrm{ty}(x))$ consisting of a natural number identifier $\mathrm{id}(x) \in \mathbb{N}$ and a type $\mathrm{ty}(x)$. Two variables are equal if and only if both their natural number identifiers and their types are equal; in particular, two variables with the same identifier $\mathrm{id}$ but distinct types $\tau_1 \neq \tau_2$ are treated as distinct variables throughout the development.

**Constructors (`Constructor`, `Constructor.ty`).** The inductive type of constructor symbols consists of five forms, each assigned a fixed type $\mathrm{ty}(c)$ as follows:
$$\begin{aligned}
\mathsf{tt} &: \mathsf{B}, \\
\mathsf{ff} &: \mathsf{B}, \\
\mathsf{nil}_\tau &: \mathsf{L}(\tau) \quad (\text{for each type } \tau), \\
\mathsf{cons}_\tau &: \diamond \multimap (\tau \multimap (\mathsf{L}(\tau) \multimap \mathsf{L}(\tau))) \quad (\text{for each type } \tau), \\
\otimes_{\tau,\rho} &: \tau \multimap (\rho \multimap (\tau \otimes \rho)) \quad (\text{for each pair of types } \tau, \rho).
\end{aligned}$$

## Terms, Contexts, Free Variables, and Substitution (`Term`, `Term.appMany`, `Context`, `DisjointCtx`, `IsCtxUnion`, `IsDisjointCtxUnion`, `freeVarOccurrences`, `freeVars`, `freeVarCard`, `IsAlmostClosed`, `IsClosed`, `maxVarId`, `renameFreeVar`, `rawSize`, `renameFreeVar_rawSize`, `substTerm`, `substTwo`)

**Raw terms (`Term`, `Term.appMany`).** The inductive type of raw (untyped) terms is generated by six constructors:
$$r, s, t ::= x \mid c \mid \lambda x.\, t \mid \langle t, s \rangle \mid t\, s \mid \{t\},$$
where $x$ ranges over typed variables (`Var`) and $c$ ranges over constructor symbols (`Constructor`). For a head term $t$ and a finite list of argument terms $[s_1, \dots, s_n]$, multi-argument application (`Term.appMany`) is defined by left-associative folding:
$$\mathrm{appMany}(t, []) = t, \qquad \mathrm{appMany}(t, s :: \vec{s}) = \mathrm{appMany}(t\, s, \vec{s}) = (\dots((t\, s_1)\, s_2)\dots)\, s_n.$$

**Contexts and context relations (`Context`, `DisjointCtx`, `IsCtxUnion`, `IsDisjointCtxUnion`).** A context $\Gamma$ is a finite list of typed variables $[v_1, \dots, v_k]$. Three set-extensional predicates are defined on contexts $\Gamma_1, \Gamma_2, \Gamma$:
- **Disjointness (`DisjointCtx`):** $\Gamma_1$ and $\Gamma_2$ are disjoint if for every variable $v$, $v \in \Gamma_1 \implies v \notin \Gamma_2$. (Multiplicity within $\Gamma_1$ or within $\Gamma_2$ is not restricted, and variables with the same numerical identifier $\mathrm{id}$ but distinct types are considered distinct.)
- **Set-extensional union (`IsCtxUnion`):** $\Gamma$ is a union of $\Gamma_1$ and $\Gamma_2$ if for every variable $v$, $v \in \Gamma \iff (v \in \Gamma_1 \lor v \in \Gamma_2)$.
- **Disjoint union (`IsDisjointCtxUnion`):** $\Gamma$ is a disjoint union of $\Gamma_1$ and $\Gamma_2$ (written $\Gamma = \Gamma_1 \uplus \Gamma_2$) if both $\mathrm{DisjointCtx}(\Gamma_1, \Gamma_2)$ and $\mathrm{IsCtxUnion}(\Gamma_1, \Gamma_2, \Gamma)$ hold.

**Free variables and closure predicates (`freeVarOccurrences`, `freeVars`, `freeVarCard`, `IsAlmostClosed`, `IsClosed`).** The list of free variable occurrences $\mathrm{FV}_{\mathrm{occ}}(t)$ is defined structurally by:
$$\begin{aligned}
\mathrm{FV}_{\mathrm{occ}}(x) &= [x], &
\mathrm{FV}_{\mathrm{occ}}(c) &= [], \\
\mathrm{FV}_{\mathrm{occ}}(\lambda x.\, t) &= [v \in \mathrm{FV}_{\mathrm{occ}}(t) \mid v \neq x], &
\mathrm{FV}_{\mathrm{occ}}(\langle t, s \rangle) &= \mathrm{FV}_{\mathrm{occ}}(t) \mathbin{+\!+} \mathrm{FV}_{\mathrm{occ}}(s), \\
\mathrm{FV}_{\mathrm{occ}}(t\, s) &= \mathrm{FV}_{\mathrm{occ}}(t) \mathbin{+\!+} \mathrm{FV}_{\mathrm{occ}}(s), &
\mathrm{FV}_{\mathrm{occ}}(\{t\}) &= \mathrm{FV}_{\mathrm{occ}}(t).
\end{aligned}$$
The set of free variables $\mathrm{FV}(t)$ (`freeVars`) is obtained by removing duplicate entries from $\mathrm{FV}_{\mathrm{occ}}(t)$, and its cardinality $|\mathrm{FV}(t)|$ (`freeVarCard`) is the length of $\mathrm{FV}(t)$. A term $t$ is **almost closed** (`IsAlmostClosed`) if every $v \in \mathrm{FV}(t)$ satisfies $\mathrm{ty}(v) = \diamond$, and **closed** (`IsClosed`) if $\mathrm{FV}(t) = []$.

**Variable renaming and capture-avoiding substitution (`maxVarId`, `renameFreeVar`, `rawSize`, `renameFreeVar_rawSize`, `substTerm`, `substTwo`).**
- $\mathrm{maxVarId}(t) \in \mathbb{N}$ computes the maximum numerical identifier $\mathrm{id}(v)$ among all variables $v$ occurring free or bound in $t$ (returning $0$ on constructor constants).
- $\mathrm{renameFreeVar}(t, x, y)$ replaces every free occurrence of variable $x$ in $t$ by variable $y$, halting under $\lambda v.\, \mathrm{body}$ if $v = x$ (without checking whether $y$ is captured by $\lambda v$ when $v = y$).
- $\mathrm{rawSize}(t) \in \mathbb{N}$ assigns size $1$ to variables and constants, $\mathrm{rawSize}(r) + 1$ to $\lambda v.\, r$ and $\{r\}$, and $\mathrm{rawSize}(r) + \mathrm{rawSize}(s) + 1$ to $\langle r, s \rangle$ and $r\, s$. The lemma `renameFreeVar_rawSize` states that for all terms $t$ and variables $x, y$, $\mathrm{rawSize}(\mathrm{renameFreeVar}(t, x, y)) = \mathrm{rawSize}(t)$.
- Single capture-avoiding substitution $t[s/x]$ (`substTerm t x s`) is defined by recursion on $\mathrm{rawSize}(t)$:
  - $v[s/x] = s$ if $v = x$, and $v$ otherwise;
  - $c[s/x] = c$;
  - $(\langle r, u \rangle)[s/x] = \langle r[s/x], u[s/x] \rangle$, $(r\, u)[s/x] = (r[s/x])\, (u[s/x])$, and $(\{r\})[s/x] = \{r[s/x]\}$;
  - $(\lambda v.\, \mathrm{body})[s/x]$ equals $\lambda v.\, \mathrm{body}$ if $v = x$; if $v \neq x$ and $v \in \mathrm{FV}_{\mathrm{occ}}(s)$, it chooses the fresh variable $v' = (\max(\mathrm{maxVarId}(\mathrm{body}), \max(\mathrm{maxVarId}(s), \mathrm{id}(x))) + 1, \mathrm{ty}(v))$ and returns $\lambda v'.\, (\mathrm{renameFreeVar}(\mathrm{body}, v, v'))[s/x]$; otherwise it returns $\lambda v.\, (\mathrm{body}[s/x])$.
- Two-variable substitution $r[t, s / x, y]$ (`substTwo r x y t s`) is defined by: if $y \in \mathrm{FV}_{\mathrm{occ}}(t)$, let $y' = (\max(\mathrm{maxVarId}(r), \max(\mathrm{maxVarId}(t), \max(\mathrm{maxVarId}(s), \max(\mathrm{id}(x), \mathrm{id}(y))))) + 1, \mathrm{ty}(y))$ and return $((\mathrm{renameFreeVar}(r, y, y'))[t/x])[s/y']$; otherwise return $(r[t/x])[s/y]$. (If $x = y$, the second substitution targets $y'$ or $y$ after $x$ has already been replaced by $t$.)

## Typing Judgment (`HasType`)

The inductive relation $\Gamma \vdash t : \tau$ (`HasType Γ t τ`) relates a context $\Gamma$, a term $t$, and a type $\tau$ via ten inference rules:
1. **Variable (`var`):** If $\Gamma' = \Gamma \uplus [x]$ (`IsDisjointCtxUnion Γ [x] Γ'`), then $\Gamma' \vdash x : \mathrm{ty}(x)$.
2. **Constructor (`const`):** For any context $\Gamma$ and constructor $c$, $\Gamma \vdash c : \mathrm{ty}(c)$.
3. **Linear abstraction (`lam`):** If $\Gamma'$ is a set-extensional union of $\Gamma$ and $[x]$ (`IsCtxUnion Γ [x] Γ'`, which does *not* require $x \notin \Gamma$) and $\Gamma' \vdash t : \rho$, then $\Gamma \vdash (\lambda x.\, t) : \mathrm{ty}(x) \multimap \rho$.
4. **Linear application (`app`):** If $\Gamma = \Gamma_1 \uplus \Gamma_2$, $\Gamma_1 \vdash t : \tau \multimap \rho$, and $\Gamma_2 \vdash s : \tau$, then $\Gamma \vdash (t\, s) : \rho$.
5. **Additive pair (`pair`):** If $\Gamma \vdash t : \tau$ and $\Gamma \vdash s : \rho$, then $\Gamma \vdash \langle t, s \rangle : \tau \times \rho$.
6. **Left projection (`projLeft`):** If $\Gamma \vdash t : \tau \times \rho$, then $\Gamma \vdash (t\, \mathsf{tt}) : \tau$.
7. **Right projection (`projRight`):** If $\Gamma \vdash t : \tau \times \rho$, then $\Gamma \vdash (t\, \mathsf{ff}) : \rho$.
8. **Boolean elimination (`boolElim`):** If $\Gamma = \Gamma_1 \uplus \Gamma_2$, $\Gamma_1 \vdash t : \mathsf{B}$, $\Gamma_2 \vdash s : \tau$, and $\Gamma_2 \vdash r : \tau$, then $\Gamma \vdash (t\, \langle s, r \rangle) : \tau$.
9. **Tensor elimination (`tensorElim`):** If $x \neq y$, $\Gamma_2' = \Gamma_2 \uplus [x, y]$, $\Gamma = \Gamma_1 \uplus \Gamma_2$, $\Gamma_1 \vdash t : \mathrm{ty}(x) \otimes \mathrm{ty}(y)$, and $\Gamma_2' \vdash s : \sigma$, then $\Gamma \vdash (t\, (\lambda x.\, \lambda y.\, s)) : \sigma$. (Note that $\mathrm{DisjointCtx}(\Gamma_2, [x, y])$ requires $x \notin \Gamma_2$ and $y \notin \Gamma_2$, while $x \neq y$ is enforced by the separate hypothesis.)
10. **List elimination / iteration (`listElim`):** If $\Gamma \vdash t : \mathsf{L}(\tau)$ and $[] \vdash s : \diamond \multimap (\tau \multimap (\rho \multimap \rho))$ (in the empty list context $[]$), then $\Gamma \vdash (t\, \{s\}) : \rho \multimap \rho$. Note that a braced term $\{s\}$ never has a standalone type under `HasType`; it can only appear as the argument of a list elimination $t\, \{s\}$.

## Lists, Conversions, and Reductions (`listEntryCount`, `IsListTerm`, `ConvStep`, `RedStep`, `RedStar`, `RedSteps`, `IsNormal`)

**Syntactic lists (`listEntryCount`, `IsListTerm`).** The partial function $\mathrm{listEntryCount}(t) \in \mathbb{N} \cup \{\bot\}$ is defined syntactically on raw terms by:
$$\mathrm{listEntryCount}(t) = \begin{cases}
0 & \text{if } t = \mathsf{nil}_\tau \text{ for some type } \tau, \\
k + 1 & \text{if } t = (((\mathsf{cons}_\tau\, d)\, a)\, l) \text{ for some } \tau, d, a, l \text{ with } \mathrm{listEntryCount}(l) = k, \\
\bot & \text{otherwise.}
\end{cases}$$
A term $l$ satisfies $\mathrm{IsListTerm}(l)$ if and only if there exists $n \in \mathbb{N}$ such that $\mathrm{listEntryCount}(l) = n$. Note that $\mathrm{listEntryCount}$ and $\mathrm{IsListTerm}$ do not check that the type subscripts $\tau$ along the spine agree, nor that the arguments $d$ and $a$ are well-typed or normal.

**Conversions (`ConvStep`).** One-step top-level conversion $t \mapsto t'$ (`ConvStep t t'`) is the inductive relation generated by eight rules:
$$\begin{aligned}
(\lambda x.\, t)\, s &\mapsto t[s/x], \\
\langle t, s \rangle\, \mathsf{tt} &\mapsto t, \\
\langle t, s \rangle\, \mathsf{ff} &\mapsto s, \\
\mathsf{tt}\, \langle t, s \rangle &\mapsto t, \\
\mathsf{ff}\, \langle t, s \rangle &\mapsto s, \\
((\otimes_{\tau,\rho}\, t)\, s)\, (\lambda x.\, \lambda y.\, r) &\mapsto r[t, s / x, y] \quad \text{provided } \mathrm{ty}(x) = \tau,\; \mathrm{ty}(y) = \rho,\; \text{and } x \neq y, \\
(\mathsf{nil}_\tau\, \{t\})\, s &\mapsto s, \\
((((\mathsf{cons}_\tau\, d)\, a)\, l)\, \{t\})\, s &\mapsto ((t\, d)\, a)\, ((l\, \{t\})\, s) \quad \text{provided } \mathrm{IsListTerm}(l).
\end{aligned}$$

**Reduction and normal forms (`RedStep`, `RedStar`, `RedSteps`, `IsNormal`).**
- **One-step reduction (`RedStep`):** $t \to t'$ holds if and only if either $t \mapsto t'$ (`ConvStep`), or $t = r\, s$ and $t' = r'\, s$ with $r \to r'$ (`appLeft`), or $t = r\, s$ and $t' = r\, s'$ with $s \to s'$ (`appRight`). Because congruence rules exist only for application, reduction is weak: no reduction step can ever occur inside a $\lambda$-abstraction $\lambda x.\, r$, inside an additive pair $\langle r, s \rangle$, or inside braces $\{r\}$.
- **Multi-step reduction (`RedStar`, `RedSteps`):** $t \to^* u$ (`RedStar t u`) is the reflexive-transitive closure of $\to$, and $t \to^k u$ (`RedSteps k t u`) holds for $k \in \mathbb{N}$ when there is a chain $t = t_0 \to t_1 \to \dots \to t_k = u$ of exactly $k$ one-step reductions.
- **Normal form (`IsNormal`):** A term $t$ is normal if there does not exist any term $t'$ such that $t \to t'$. Because $\to$ does not reduce under $\lambda$, $\langle \cdot, \cdot \rangle$, or $\{\cdot\}$, any term whose outermost constructor is $\lambda$, $\langle \cdot, \cdot \rangle$, $\{\cdot\}$, a variable, or a constant is vacuously normal regardless of whether its proper subterms contain redexes.

## Term Length and Step-Bound Measure (`termLength`, `truncId`, `PolyLe`, `theta`, `stepMeasure`)

**Term length (`termLength`).** For any raw term $t$ (see `Def_AehligSchwichtenberg2002_Syntax.lean`), its length $|t| \in \mathbb{N}$ is defined structurally by:
$$\begin{aligned}
|x| &= 1 \quad (\text{for any variable } x), \\
|c| &= 1 \quad (\text{for any constructor } c), \\
|t\, s| &= |t| + |s|, \\
|\lambda x.\, s| &= |s| + 1, \\
|\langle t, s \rangle| &= \max(|t|, |s|) + 1, \\
|\{t\}| &= 0.
\end{aligned}$$
In particular, any braced subterm $\{t\}$ contributes $0$ to the length of the enclosing term.

**Truncated identity and pointwise order (`truncId`, `PolyLe`).** For $n, m \in \mathbb{N}$, the truncated identity is $\mathrm{truncId}(n, m) = \min(n, m)$. For two functions $f, g : \mathbb{N} \to \mathbb{N}$, the pointwise order $f \preceq g$ (`PolyLe f g`) asserts that $f(m) \le g(m)$ for all $m \in \mathbb{N}$.

**Polynomial bound of a term (`theta`, `stepMeasure`).** For every raw term $t$ and natural number $m \in \mathbb{N}$, the value $\vartheta(t)(m) \in \mathbb{N}$ (`theta t m`) is defined recursively on $t$ by:
$$\begin{aligned}
\vartheta(x)(m) &= 0, \\
\vartheta(c)(m) &= 0, \\
\vartheta(t\, \{h\})(m) &= \begin{cases}
\vartheta(t)(m) + \min(n, m) \cdot \vartheta(h)(m) + \min(n, m) \cdot |h| & \text{if } \mathrm{listEntryCount}(t) = n \in \mathbb{N}, \\
\vartheta(t)(m) + m \cdot \vartheta(h)(m) + m \cdot |h| & \text{if } \mathrm{listEntryCount}(t) = \bot,
\end{cases} \\
\vartheta(t\, s)(m) &= \vartheta(t)(m) + \vartheta(s)(m) \quad (\text{when } s \text{ is not of the form } \{h\}), \\
\vartheta(\lambda x.\, t)(m) &= \vartheta(t)(m), \\
\vartheta(\langle t, s \rangle)(m) &= \max(\vartheta(t)(m), \vartheta(s)(m)), \\
\vartheta(\{h\})(m) &= m \cdot \vartheta(h)(m) + m \cdot |h|.
\end{aligned}$$
Here $\mathrm{listEntryCount}(t)$ is the syntactic list-entry counter on raw terms ($0$ on $\mathsf{nil}_\tau$, $k + 1$ on $(((\mathsf{cons}_\tau\, d)\, a)\, l)$ when $\mathrm{listEntryCount}(l) = k$, and $\bot$ otherwise). Notice that when $\mathrm{listEntryCount}(t) = \bot$, the clause for $\vartheta(t\, \{h\})(m)$ coincides with $\vartheta(t)(m) + \vartheta(\{h\})(m)$. For a term $t$ and parameter $N \in \mathbb{N}$, the combined step measure (`stepMeasure t N`) is defined as:
$$\mathrm{stepMeasure}(t, N) = \vartheta(t)(N) + |t|.$$

## Brace Depth, Polynomial Boundedness, and Canonical List Inputs (`braceDepth`, `IsPolyBoundedOfDegree`, `IsPolyBounded`, `IsCanonicalListInput`, `ValidBinListInputs`, `sumListLengths`)

**Brace-nesting depth and polynomial growth (`braceDepth`, `IsPolyBoundedOfDegree`, `IsPolyBounded`).**
- The brace-nesting depth $\mathrm{braceDepth}(t) \in \mathbb{N}$ of a raw term $t$ is defined by $\mathrm{braceDepth}(x) = \mathrm{braceDepth}(c) = 0$, $\mathrm{braceDepth}(\lambda x.\, t) = \mathrm{braceDepth}(t)$, $\mathrm{braceDepth}(\langle t, s \rangle) = \mathrm{braceDepth}(t\, s) = \max(\mathrm{braceDepth}(t), \mathrm{braceDepth}(s))$, and $\mathrm{braceDepth}(\{h\}) = \mathrm{braceDepth}(h) + 1$.
- For a function $B : \mathbb{N} \to \mathbb{N}$ and degree $d \in \mathbb{N}$, $\mathrm{IsPolyBoundedOfDegree}(B, d)$ holds if and only if there exist constants $c_0, c_1 \in \mathbb{N}$ such that for all $n \in \mathbb{N}$,
  $$B(n) \le c_0 (n + 1)^d + c_1.$$
- A function $B : \mathbb{N} \to \mathbb{N}$ satisfies $\mathrm{IsPolyBounded}(B)$ if there exists some $d \in \mathbb{N}$ such that $\mathrm{IsPolyBoundedOfDegree}(B, d)$ holds.

**Canonical list inputs (`IsCanonicalListInput`, `ValidBinListInputs`, `sumListLengths`).**
- For a type $\tau$, a raw term $l$, and a natural number $n \in \mathbb{N}$, $\mathrm{IsCanonicalListInput}(\tau, l, n)$ holds if and only if there exists a context $\Gamma$ such that:
  1. every variable $v \in \Gamma$ has type $\mathrm{ty}(v) = \diamond$;
  2. $\Gamma \vdash l : \mathsf{L}(\tau)$ (`HasType Γ l (.list τ)`);
  3. $l$ is in normal form (`IsNormal l`, i.e., no one-step reduction $l \to l'$ exists); and
  4. $\mathrm{listEntryCount}(l) = n$.
- The inductive relation $\mathrm{ValidBinListInputs}(\Gamma, [l_1, \dots, l_k], [n_1, \dots, n_k])$ relates an accumulated context $\Gamma$, a list of input terms $[l_1, \dots, l_k]$, and a list of natural numbers $[n_1, \dots, n_k]$ via two constructors:
  - **Empty tuple (`nil`):** $\mathrm{ValidBinListInputs}([], [], [])$ holds.
  - **Step (`cons`):** Given contexts $\Gamma_{\mathrm{acc}}, \Gamma_l, \Gamma_{\mathrm{new}}$, a term $l$, a natural number $n \in \mathbb{N}$, a term list $\vec{l}$, and a number list $\vec{n}$, if every $v \in \Gamma_l$ has $\mathrm{ty}(v) = \diamond$, $\Gamma_l \vdash l : \mathsf{L}(\mathsf{B})$, $l$ is normal, $\mathrm{listEntryCount}(l) = n$, $\Gamma_{\mathrm{new}} = \Gamma_{\mathrm{acc}} \uplus \Gamma_l$ (`IsDisjointCtxUnion Γ_acc Γ_l Γ_new`), and $\mathrm{ValidBinListInputs}(\Gamma_{\mathrm{acc}}, \vec{l}, \vec{n})$ holds, then $\mathrm{ValidBinListInputs}(\Gamma_{\mathrm{new}}, l :: \vec{l}, n :: \vec{n})$ holds.
- For a list of natural numbers $\vec{n} = [n_1, \dots, n_k]$, $\mathrm{sumListLengths}(\vec{n}) = \sum_{i=1}^k n_i$ (with $\mathrm{sumListLengths}([]) = 0$).

## Theorem `lemma_3_4`

Let $\Gamma_1, \Gamma_1', \Gamma_2, \Gamma$ be contexts (finite lists of typed variables $v = (\mathrm{id}(v), \mathrm{ty}(v)) \in \mathbb{N} \times \mathsf{Ty}$), let $x$ be a typed variable, let $t$ and $s$ be raw terms, and let $\tau$ be a type in the finite linear type system $\mathsf{Ty}$. Assume the following four hypotheses:
1. **Context union for $x$ (`hu₁`):** $\Gamma_1'$ is a set-extensional union of $\Gamma_1$ and the singleton context $[x]$ (`IsCtxUnion Γ₁ [x] Γ₁'`), meaning that for every variable $v$, $v \in \Gamma_1' \iff (v \in \Gamma_1 \lor v = x)$. Note that this hypothesis does *not* require $x \notin \Gamma_1$; $x$ may or may not belong to $\Gamma_1$.
2. **Typing of $t$ (`ht`):** $\Gamma_1' \vdash t : \tau$ (`HasType Γ₁' t τ`) in the affine linear typing system.
3. **Typing of $s$ (`hs`):** $\Gamma_2 \vdash s : \mathrm{ty}(x)$ (`HasType Γ₂ s x.ty`).
4. **Disjoint union of remaining contexts (`hdj`):** $\Gamma$ is a set-extensional disjoint union of $\Gamma_1$ and $\Gamma_2$ (`IsDisjointCtxUnion Γ₁ Γ₂ Γ`), meaning that no variable $v$ belongs to both $\Gamma_1$ and $\Gamma_2$, and for every variable $v$, $v \in \Gamma \iff (v \in \Gamma_1 \lor v \in \Gamma_2)$.

Then the capture-avoiding substitution $t[s/x]$ (`substTerm t x s`, which replaces every free occurrence of $x$ in $t$ by $s$ while renaming bound variables of $t$ that occur free in $s$ to fresh variable identifiers) is well-typed in context $\Gamma$ with type $\tau$:
$$\Gamma \vdash t[s/x] : \tau.$$
In the edge case where $x \in \Gamma_1$ (permitted by `hu₁`), disjointness `hdj` ensures $x \notin \Gamma_2$, and $x$ remains present in the resulting context $\Gamma$ even though all free occurrences of $x$ in $t$ have been replaced by $s$.

## Theorem `lemma_3_5`

Let $\Gamma$ be a context (a finite list of typed variables), let $t$ and $t'$ be raw terms, and let $\tau$ be a type in $\mathsf{Ty}$. Assume:
1. **Typing (`ht`):** $\Gamma \vdash t : \tau$ (`HasType Γ t τ`) in the affine linear type system.
2. **One-step reduction (`hred`):** $t \to t'$ (`RedStep t t'`), meaning that $t'$ is obtained from $t$ by applying one of the eight top-level conversions (`ConvStep`) either at the root of $t$ or inside the left or right subterm of an application chain:
   - $(\lambda x.\, r)\, s \mapsto r[s/x]$,
   - $\langle r, s \rangle\, \mathsf{tt} \mapsto r$ or $\langle r, s \rangle\, \mathsf{ff} \mapsto s$,
   - $\mathsf{tt}\, \langle r, s \rangle \mapsto r$ or $\mathsf{ff}\, \langle r, s \rangle \mapsto s$,
   - $((\otimes_{\sigma,\rho}\, r)\, s)\, (\lambda x.\, \lambda y.\, u) \mapsto u[r, s / x, y]$ with $\mathrm{ty}(x) = \sigma$, $\mathrm{ty}(y) = \rho$, and $x \neq y$,
   - $(\mathsf{nil}_\sigma\, \{r\})\, s \mapsto s$, or
   - $((((\mathsf{cons}_\sigma\, d)\, a)\, l)\, \{r\})\, s \mapsto ((r\, d)\, a)\, ((l\, \{r\})\, s)$ where $\mathrm{IsListTerm}(l)$ holds (i.e., $l$ is built from $\mathsf{nil}$ and ternary applications of $\mathsf{cons}$).

Then $t'$ has the same type $\tau$ in the exact same context list $\Gamma$:
$$\Gamma \vdash t' : \tau.$$

## Theorem `corollary_4_4`

Let $\tau$ be a type in $\mathsf{Ty}$, let $f, l, w$ be raw terms, and let $n \in \mathbb{N}$ be a natural number. Assume the following four hypotheses:
1. **Closed list-to-list function (`hf`):** $[] \vdash f : \mathsf{L}(\tau) \multimap \mathsf{L}(\tau)$ (`HasType [] f (.lolli (.list τ) (.list τ)`) in the empty typing context $[]$.
2. **Canonical list input of length $n$ (`hl`):** $\mathrm{IsCanonicalListInput}(\tau, l, n)$ holds, meaning there exists a context $\Gamma$ such that:
   - every variable $v \in \Gamma$ has type $\mathrm{ty}(v) = \diamond$,
   - $\Gamma \vdash l : \mathsf{L}(\tau)$ (`HasType Γ l (.list τ)`),
   - $l$ is in normal form (`IsNormal l`, i.e., there is no $l'$ with $l \to l'$), and
   - $\mathrm{listEntryCount}(l) = n$ (meaning $l$ is syntactically an $n$-fold spine of ternary $\mathsf{cons}$ applications ending in $\mathsf{nil}$).
3. **Reduction to $w$ (`hred`):** The application $f\, l$ reduces in zero or more one-step reductions to $w$, i.e., $f\, l \to^* w$ (`RedStar (.app f l) w`).
4. **Normal form of $w$ (`hnorm`):** $w$ is in normal form (`IsNormal w`, i.e., there is no $w'$ with $w \to w'$).

Then there exists a natural number $m \in \mathbb{N}$ such that
$$\mathrm{listEntryCount}(w) = m \quad \text{and} \quad m \le n.$$
Note that the existence of a normal form $w$ of $f\, l$ is assumed as a hypothesis (`hred` and `hnorm`) rather than asserted in the conclusion of this theorem. In the degenerate case $n = 0$ (where $l = \mathsf{nil}_\tau$), the conclusion forces $m = 0$, so $w$ must be a $0$-entry list ($\mathsf{nil}_{\tau'}$).

## Theorem `lemma_4_7`

1. **Typing of $t$ (`ht`):** $\Gamma_1 \vdash t : \tau$ (`HasType Γ₁ t τ`).
2. **Typing of $s$ (`hs`):** $\Gamma_2 \vdash s : \rho$ (`HasType Γ₂ s ρ`).
3. **Disjoint contexts (`hdj`):** $\Gamma_1$ and $\Gamma_2$ are set-wise disjoint (`DisjointCtx Γ₁ Γ₂`), meaning that for every variable $v$, $v \in \Gamma_1 \implies v \notin \Gamma_2$.

Then $\vartheta(t[s/x]) \preceq \vartheta(t) + \vartheta(s)$ holds in the pointwise order (`PolyLe`), meaning that for every natural number $m \in \mathbb{N}$,
$$\vartheta(t[s/x])(m) \le \vartheta(t)(m) + \vartheta(s)(m),$$
where $t[s/x]$ (`substTerm t x s`) is the capture-avoiding substitution of $s$ for $x$ in $t$, and $\vartheta(r)(m) \in \mathbb{N}$ (`theta r m`) is the polynomial step-bound valuation defined by $\vartheta(v)(m) = \vartheta(c)(m) = 0$, $\vartheta(\lambda v.\, r)(m) = \vartheta(r)(m)$, $\vartheta(\langle r, u \rangle)(m) = \max(\vartheta(r)(m), \vartheta(u)(m))$, $\vartheta(\{h\})(m) = m \cdot \vartheta(h)(m) + m \cdot |h|$, $\vartheta(r\, \{h\})(m) = \vartheta(r)(m) + \min(n, m) \cdot (\vartheta(h)(m) + |h|)$ if $\mathrm{listEntryCount}(r) = n$ and $\vartheta(r)(m) + m \cdot (\vartheta(h)(m) + |h|)$ if $\mathrm{listEntryCount}(r) = \bot$, and $\vartheta(r\, u)(m) = \vartheta(r)(m) + \vartheta(u)(m)$ when $u$ is not braced.

## Theorem `theorem_4_8`

Let $\Gamma$ be a context (a finite list of typed variables), let $t$ be a raw term, and let $\tau$ be a type in $\mathsf{Ty}$. Assume that $\Gamma \vdash t : \tau$ (`HasType Γ t τ`) in the affine linear typing system.

Then both of the following properties hold:
1. **Strict decrease under one-step reduction:** For every natural number $N \in \mathbb{N}$ and every raw term $t'$, if $|\mathrm{FV}(t)| \le N$ (`freeVarCard t ≤ N`, where $|\mathrm{FV}(t)|$ is the number of distinct free variables of $t$) and $t \to t'$ (`RedStep t t'`), then
   $$\vartheta(t')(N) + |t'| < \vartheta(t)(N) + |t| \qquad (\text{i.e., } \mathrm{stepMeasure}(t', N) < \mathrm{stepMeasure}(t, N)).$$
2. **Global bound on reduction length:** For every natural number $k \in \mathbb{N}$ and every raw term $t'$, if $t \to^k t'$ (`RedSteps k t t'`, meaning there is a reduction sequence $t = t_0 \to t_1 \to \dots \to t_k = t'$ of length $k$), then
   $$k \le \vartheta(t)(|\mathrm{FV}(t)|) + |t| \qquad (\text{i.e., } k \le \mathrm{stepMeasure}(t, |\mathrm{FV}(t)|)).$$

Here $|r| \in \mathbb{N}$ (`termLength r`) is the term length defined by $|x| = |c| = 1$, $|r\, s| = |r| + |s|$, $|\lambda x.\, r| = |r| + 1$, $|\langle r, s \rangle| = \max(|r|, |s|) + 1$, and $|\{r\}| = 0$; and $\vartheta(r)(N) \in \mathbb{N}$ (`theta r N`) is the polynomial step-bound valuation evaluated at $N$. In the special case where $t$ is closed ($|\mathrm{FV}(t)| = 0$), part (1) applies for any $N \ge 0$ (including $N = 0$), and part (2) bounds any reduction sequence starting from $t$ by $\vartheta(t)(0) + |t|$ steps.

## Theorem `corollary_4_9`

Let $k \in \mathbb{N}$ be a natural number (the number of list arguments) and let $t$ be a raw term. Assume that $t$ is typed in the empty context $[]$ as a $k$-ary iterated linear function on binary lists (`ht`):
$$[] \vdash t : \underbrace{\mathsf{L}(\mathsf{B}) \multimap (\mathsf{L}(\mathsf{B}) \multimap \dots (\mathsf{L}(\mathsf{B})}_{k\text{ copies}} \multimap \mathsf{L}(\mathsf{B}))\dots)$$
(`HasType [] t (Ty.lolliMany (List.replicate k Ty.bin) Ty.bin)`).

Then there exists a bounding function $B : \mathbb{N} \to \mathbb{N}$ satisfying both of the following conditions:
1. **Polynomial growth bound of degree $\max(\mathrm{braceDepth}(t), 1)$:** $\mathrm{IsPolyBoundedOfDegree}(B, \max(\mathrm{braceDepth}(t), 1))$ holds; that is, there exist constants $c_0, c_1 \in \mathbb{N}$ such that for all $n \in \mathbb{N}$,
   $$B(n) \le c_0 (n + 1)^{\max(\mathrm{braceDepth}(t), 1)} + c_1,$$
   where $\mathrm{braceDepth}(t) \in \mathbb{N}$ is the maximum nesting depth of braces $\{\cdot\}$ in $t$. (Note that when $\mathrm{braceDepth}(t) = 0$, the exponent in the polynomial bound is $\max(0, 1) = 1$, i.e., an affine bound $c_0(n+1) + c_1$, rather than degree $0$.)
2. **Bounded normalization and non-size-increasing output on valid binary-list inputs:** For every context $\Gamma$, every list of raw terms $\vec{l} = [l_1, \dots, l_k]$ of length $k$ (`ls.length = k`), and every list of natural numbers $\vec{n} = [n_1, \dots, n_k]$, if $\mathrm{ValidBinListInputs}(\Gamma, \vec{l}, \vec{n})$ holds—meaning that starting from the empty context $[]$, each input $l_i$ has a context $\Gamma_{l_i}$ disjoint from the union of the preceding input contexts, with $\Gamma = \Gamma_{l_1} \uplus \dots \uplus \Gamma_{l_k}$, such that every variable $v \in \Gamma_{l_i}$ has type $\diamond$, $\Gamma_{l_i} \vdash l_i : \mathsf{L}(\mathsf{B})$, $l_i$ is in normal form (`IsNormal l_i`), and $\mathrm{listEntryCount}(l_i) = n_i$—then there exist natural numbers $\mathrm{steps}, m \in \mathbb{N}$ and a raw term $w$ such that:
   - the iterated application $(\dots((t\, l_1)\, l_2)\dots)\, l_k$ (`Term.appMany t ls`) reduces to $w$ in exactly $\mathrm{steps}$ one-step reductions (`RedSteps steps (Term.appMany t ls) w`),
   - $w$ is in normal form (`IsNormal w`),
   - $\mathrm{listEntryCount}(w) = m$,
   - the output list entry count is at most the sum of the input list entry counts:
     $$m \le \sum_{i=1}^k n_i \qquad (\text{`m ≤ sumListLengths ns`}),$$
   - and the number of reduction steps is bounded by $B$ evaluated at the sum of the input list entry counts:
     $$\mathrm{steps} \le B\!\left(\sum_{i=1}^k n_i\right) \qquad (\text{`steps ≤ B (sumListLengths ns)`}).$$

Edge cases and representation details:
- When $k = 0$, `List.replicate 0 Ty.bin` is $[]$, so the hypothesis is $[] \vdash t : \mathsf{L}(\mathsf{B})$, the only valid input lists are $\vec{l} = []$ and $\vec{n} = []$ with $\Gamma = []$ and $\mathrm{sumListLengths}([]) = 0$, and the conclusion states that $t$ normalizes in $\mathrm{steps} \le B(0)$ steps to a normal form $w$ with $\mathrm{listEntryCount}(w) = 0$ (i.e., $\mathsf{nil}$).
- The complexity bound $\mathrm{steps} \le B(\sum_{i=1}^k n_i)$ counts the number of term-rewriting steps in `RedStep` (weak reduction at the root or under applications), rather than bit-level or Turing-machine time steps.
- Each canonical binary-list input $l_i$ is required to be a normal term of type $\mathsf{L}(\mathsf{B})$ in a $\diamond$-only context $\Gamma_{l_i}$ with $\mathrm{listEntryCount}(l_i) = n_i$; in particular, $l_i$ contains $n_i$ distinct free variables of type $\diamond$ (in the first arguments of $\mathsf{cons}_{\mathsf{B}}$), and the pairwise disjointness in `ValidBinListInputs` forces the $k$ input lists to use disjoint sets of $\diamond$-variables.
