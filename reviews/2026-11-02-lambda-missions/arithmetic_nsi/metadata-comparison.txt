**Types (`Ty`, `Ty.bool`, `Ty.nat`, `Ty.bin`, `Ty.lolliMany`).**
The inductive type $\mathrm{Ty}$ of types is freely generated by two base types, the unit type $U$ and the diamond type $\diamond$, together with unary list formation $L(\rho)$ and four binary type constructors: linear implication $\rho \multimap \sigma$, tensor product $\rho \otimes \sigma$, Cartesian product $\rho \times \sigma$, and disjoint sum $\rho + \sigma$. Three abbreviations are defined: the boolean type $\mathrm{B} := U + U$, the unary natural number type $\mathrm{N} := L(U)$, and the binary natural number type $\mathrm{Bin} := L(\mathrm{B}) = L(U + U)$. For a finite list of types $[\rho_1, \dots, \rho_n]$ and a target type $\tau$, the iterated linear function type $\mathrm{lolliMany}([\rho_1, \dots, \rho_n], \tau)$ is defined by right-associated recursion as $\rho_1 \multimap (\rho_2 \multimap \cdots \multimap (\rho_n \multimap \tau) \cdots)$, returning $\tau$ when the list is empty ($n = 0$).

**Set-theoretic interpretation (`SetModel`).**
For each type $\rho \in \mathrm{Ty}$, $\mathcal{S}^\rho$ ($\mathrm{SetModel}(\rho)$) is a Type defined recursively on $\rho$:
$$\mathcal{S}^U = \mathrm{PUnit}, \quad \mathcal{S}^\diamond = \mathrm{Unit}, \quad \mathcal{S}^{L(\rho)} = \mathrm{List}(\mathcal{S}^\rho), \quad \mathcal{S}^{\rho \multimap \sigma} = (\mathcal{S}^\rho \to \mathcal{S}^\sigma),$$
$$\mathcal{S}^{\rho \otimes \sigma} = \mathcal{S}^\rho \times \mathcal{S}^\sigma, \quad \mathcal{S}^{\rho \times \sigma} = \mathcal{S}^\rho \times \mathcal{S}^\sigma, \quad \mathcal{S}^{\rho + \sigma} = \mathcal{S}^\rho \sqcup \mathcal{S}^\sigma.$$
Note that both $\mathcal{S}^U$ and $\mathcal{S}^\diamond$ are concretely fixed as singleton (one-element) unit types, and $\mathcal{S}^{\rho \multimap \sigma}$ is the full metalanguage function space from $\mathcal{S}^\rho$ to $\mathcal{S}^\sigma$.

**Typed variables and constants (`Var`, `Const`, `Const.ty`, `Const.isConstructor`).**
A term variable $x \in \mathrm{Var}$ is a pair $(\mathrm{id}, \mathrm{ty})$ consisting of a natural number identifier $\mathrm{id} \in \mathbb{N}$ and an embedded type $\mathrm{ty} \in \mathrm{Ty}$; two variables are equal if and only if both their identifiers and their types are equal. A constant $c \in \mathrm{Const}$ is one of eleven type-indexed syntactic forms, each assigned a fixed type $c.\mathrm{ty} \in \mathrm{Ty}$:
- $\varepsilon : U$,
- $\mathrm{nil}_\rho : L(\rho)$,
- $\mathrm{cons}_\rho : \diamond \multimap (\rho \multimap (L(\rho) \multimap L(\rho)))$,
- $\otimes^+_{\rho,\sigma} : \rho \multimap (\sigma \multimap (\rho \otimes \sigma))$,
- $\otimes^-_{\rho,\sigma,\tau} : (\rho \otimes \sigma) \multimap ((\rho \multimap (\sigma \multimap \tau)) \multimap \tau)$,
- $\times^+_{\rho,\sigma,\tau} : (\tau \multimap \rho) \multimap ((\tau \multimap \sigma) \multimap (\tau \multimap (\rho \times \sigma)))$,
- $\mathrm{fst}_{\rho,\sigma} : (\rho \times \sigma) \multimap \rho$,
- $\mathrm{snd}_{\rho,\sigma} : (\rho \times \sigma) \multimap \sigma$,
- $\mathrm{inl}_{\rho,\sigma} : \rho \multimap (\rho + \sigma)$,
- $\mathrm{inr}_{\rho,\sigma} : \sigma \multimap (\rho + \sigma)$,
- $+^-_{\rho,\sigma,\tau} : (\rho + \sigma) \multimap (((\rho \multimap \tau) \times (\sigma \multimap \tau)) \multimap \tau)$.

The boolean predicate $\mathrm{isConstructor}(c)$ evaluates to $\mathrm{true}$ if $c$ is one of $\varepsilon$, $\otimes^+_{\rho,\sigma}$, $\mathrm{inl}_{\rho,\sigma}$, $\mathrm{inr}_{\rho,\sigma}$, $\mathrm{nil}_\rho$, or $\mathrm{cons}_\rho$, and $\mathrm{false}$ otherwise (in particular, $\mathrm{isConstructor}(\times^+_{\rho,\sigma,\tau}) = \mathrm{false}$).

**Raw terms and abbreviations (`Term`, `appMany`, `lamMany`, `idTerm`, `tt`, `ff`, `zeroNat`, `succNat`, `pi0`, `pi1`).**
The inductive type $\mathrm{Term}$ of raw terms is generated by: variables $x$, constants $c$, lambda abstractions $\lambda x.\, r$ (where $x \in \mathrm{Var}$), binary applications $r\,s$, and list iterations $r\{s\}$. For a term $r$ and a list of argument terms $[s_1, \dots, s_n]$, $\mathrm{appMany}(r, [s_1, \dots, s_n])$ is the left-associated iterated application $(\cdots((r\,s_1)\,s_2)\cdots)\,s_n$ (or $r$ when $n = 0$). For a list of variables $[x_1, \dots, x_n]$ and a body $r$, $\mathrm{lamMany}([x_1, \dots, x_n], r)$ is $\lambda x_1.\,\cdots\,\lambda x_n.\, r$ (or $r$ when $n = 0$). The derived term constructors are:
- $\mathrm{idTerm}(\rho) := \lambda x_0^\rho.\, x_0^\rho$, where $x_0^\rho = (0, \rho)$;
- $\mathrm{tt} := \mathrm{inl}_{U,U}\,\varepsilon$ and $\mathrm{ff} := \mathrm{inr}_{U,U}\,\varepsilon$;
- $\mathrm{zeroNat} := \mathrm{nil}_U$ and $\mathrm{succNat}(d, r) := (((\mathrm{cons}_U\,d)\,\varepsilon)\,r)$;
- $\pi_0(\rho, \sigma, r) := ((\otimes^-_{\rho,\sigma,\rho}\,r)\,(\lambda x_0^\rho.\,\lambda x_1^\sigma.\, x_0^\rho))$ and $\pi_1(\rho, \sigma, r) := ((\otimes^-_{\rho,\sigma,\sigma}\,r)\,(\lambda x_0^\rho.\,\lambda x_1^\sigma.\, x_1^\sigma))$, where $x_0^\rho = (0, \rho)$ and $x_1^\sigma = (1, \sigma)$.

**Free variables and closedness predicates (`freeVarOccurrences`, `freeVars`, `freeVarCount`, `DisjointFV`, `IsClosed`, `IsAlmostClosed`).**
For any raw term $r$, $\mathrm{freeVarOccurrences}(r)$ is a list of variables preserving multiplicity and left-to-right order: it is $[x]$ for a variable $x$, $[]$ for a constant $c$, the list $\mathrm{freeVarOccurrences}(r)$ with all occurrences equal to $x$ removed for $\lambda x.\, r$, and the list concatenation $\mathrm{freeVarOccurrences}(r) \mathbin{+\!+} \mathrm{freeVarOccurrences}(s)$ for both $r\,s$ and $r\{s\}$. The list $\mathrm{freeVars}(r)$ is obtained by deduplicating $\mathrm{freeVarOccurrences}(r)$, and $\mathrm{freeVarCount}(r) := |\mathrm{freeVarOccurrences}(r)| \in \mathbb{N}$ is the number of free variable occurrences in $r$ counted with multiplicity. Two terms $r, s$ have disjoint free variables, written $\mathrm{DisjointFV}(r, s)$, if no variable $v \in \mathrm{freeVarOccurrences}(r)$ appears in $\mathrm{freeVarOccurrences}(s)$. A term $r$ is closed ($\mathrm{IsClosed}(r)$) if $\mathrm{freeVarOccurrences}(r) = []$, and almost closed ($\mathrm{IsAlmostClosed}(r)$) if every variable $v \in \mathrm{freeVarOccurrences}(r)$ has type $v.\mathrm{ty} = \diamond$.

**Variable renaming and capture-avoiding substitution (`maxVarId`, `renameFreeVar`, `rawSize`, `renameFreeVar_rawSize`, `substTerm`, `substMany`).**
For a term $r$, $\mathrm{maxVarId}(r) \in \mathbb{N}$ is the maximum identifier $v.\mathrm{id}$ among all free and $\lambda$-bound variables occurring in $r$ (and $0$ if $r$ contains only constants). The function $\mathrm{renameFreeVar}(r, x, y)$ replaces every free occurrence of variable $x$ in $r$ with variable $y$, halting under $\lambda v$ when $v = x$ without checking for capture of $y$. Its structural size $\mathrm{rawSize}(r)$ ($1$ for variables and constants, $\mathrm{rawSize}(r) + 1$ for $\lambda x.\,r$, and $\mathrm{rawSize}(r) + \mathrm{rawSize}(s) + 1$ for $r\,s$ and $r\{s\}$) is preserved by $\mathrm{renameFreeVar}$ ($\mathrm{renameFreeVar\_rawSize}$). Capture-avoiding substitution $r[s/x]$ ($\mathrm{substTerm}(r, x, s)$) replaces free occurrences of $x$ in $r$ by $s$: at a binder $\lambda v.\,\mathrm{body}$, if $v = x$ the abstraction is returned unchanged; if $v \neq x$ and $v \in \mathrm{freeVarOccurrences}(s)$, the bound variable $v$ is first renamed via $\mathrm{renameFreeVar}$ to $v' := (\max(\mathrm{maxVarId}(\mathrm{body}), \max(\mathrm{maxVarId}(s), x.\mathrm{id})) + 1, v.\mathrm{ty})$ before recursively substituting $s$ for $x$; otherwise substitution proceeds directly into $\mathrm{body}$. Note that $\mathrm{substTerm}$ does not check whether $x.\mathrm{ty}$ matches the type of $s$. For a list of pairs $[(x_1, s_1), \dots, (x_n, s_n)]$, $\mathrm{substMany}(r, [(x_1, s_1), \dots, (x_n, s_n)])$ applies $\mathrm{substTerm}$ sequentially from left to right: $(\cdots(r[s_1/x_1])\cdots)[s_n/x_n]$ (because it is sequential rather than simultaneous, free occurrences of $x_j$ inside an earlier replacement term $s_i$ for $i < j$ will also be substituted by $s_j$).

**Linear typing and weak typing (`HasType`, `WeaklyTyped`).**
The binary relation $\mathrm{HasType}(r, \rho)$ (meaning term $r$ has linear type $\rho$) is inductively defined by five rules:
1. Every variable $x$ has type $x.\mathrm{ty}$.
2. Every constant $c$ has type $c.\mathrm{ty}$.
3. If $\mathrm{HasType}(r, \sigma)$, then $\mathrm{HasType}(\lambda x.\, r, x.\mathrm{ty} \multimap \sigma)$ (with no restriction on how many times $x$ occurs free in $r$).
4. If $\mathrm{HasType}(r, \rho \multimap \sigma)$, $\mathrm{HasType}(s, \rho)$, and $\mathrm{DisjointFV}(r, s)$, then $\mathrm{HasType}(r\,s, \sigma)$.
5. If $\mathrm{HasType}(r, L(\rho))$, $\mathrm{HasType}(s, \diamond \multimap (\rho \multimap (\tau \multimap \tau)))$, and $\mathrm{IsClosed}(s)$, then $\mathrm{HasType}(r\{s\}, \tau \multimap \tau)$.

The weak typing relation $\mathrm{WeaklyTyped}(r, \rho)$ is defined by the exact same five rules, except that the side condition $\mathrm{DisjointFV}(r, s)$ in the application rule and the side condition $\mathrm{IsClosed}(s)$ in the iteration rule are dropped.

**List terms (`listEntryCount`, `IsListTerm`).**
For any term $t$, $\mathrm{listEntryCount}(t) \in \mathrm{Option}(\mathbb{N})$ is defined by structural recursion:
$$\mathrm{listEntryCount}(\mathrm{nil}_\rho) = \mathrm{some}(0), \qquad \mathrm{listEntryCount}(((\mathrm{cons}_\rho\,d)\,r)\,l) = \begin{cases} \mathrm{some}(k + 1) & \text{if } \mathrm{listEntryCount}(l) = \mathrm{some}(k), \\ \mathrm{none} & \text{if } \mathrm{listEntryCount}(l) = \mathrm{none}, \end{cases}$$
and $\mathrm{listEntryCount}(t) = \mathrm{none}$ for all other terms $t$. A term $t$ satisfies $\mathrm{IsListTerm}(t)$ if and only if there exists $n \in \mathbb{N}$ such that $\mathrm{listEntryCount}(t) = \mathrm{some}(n)$. Note that on untyped terms, $\mathrm{listEntryCount}$ does not require the type subscripts $\rho$ on the $\mathrm{cons}_\rho$ and $\mathrm{nil}_\rho$ constants along the spine to be equal, nor does it constrain the subterms $d$ and $r$.

**Conversions, reductions, normal forms, and canonical forms (`ConvStep`, `RedStep`, `RedStar`, `RedSteps`, `IsNormal`, `HasCanonicalNormalForm`).**
The one-step conversion relation $r \mapsto r'$ ($\mathrm{ConvStep}(r, r')$) is inductively defined by eight rules for any types $\rho, \sigma, \tau$ and terms $r, s, t, d, l$:
1. $(\lambda x.\, r)\,s \mapsto r[s/x]$;
2. $((\otimes^-_{\rho,\sigma,\tau}\,((\otimes^+_{\rho,\sigma}\,r)\,s))\,t) \mapsto (t\,r)\,s$;
3. $(\mathrm{fst}_{\rho,\sigma}\,(((\times^+_{\rho,\sigma,\tau}\,r)\,s)\,t)) \mapsto r\,t$;
4. $(\mathrm{snd}_{\rho,\sigma}\,(((\times^+_{\rho,\sigma,\tau}\,r)\,s)\,t)) \mapsto s\,t$;
5. $((+^-_{\rho,\sigma,\tau}\,(\mathrm{inl}_{\rho,\sigma}\,r))\,s) \mapsto ((\mathrm{fst}_{\rho \multimap \tau, \sigma \multimap \tau}\,s)\,r)$;
6. $((+^-_{\rho,\sigma,\tau}\,(\mathrm{inr}_{\rho,\sigma}\,r))\,s) \mapsto ((\mathrm{snd}_{\rho \multimap \tau, \sigma \multimap \tau}\,s)\,r)$;
7. $((\mathrm{nil}_\rho\{s\})\,t) \mapsto t$;
8. $((((\mathrm{cons}_\rho\,d)\,r)\,l)\{s\})\,t \mapsto (((s\,d)\,r)\,((l\{s\})\,t))$ provided $\mathrm{IsListTerm}(l)$ holds.

One-step reduction $r \to r'$ ($\mathrm{RedStep}(r, r')$) is the closure of $\mathrm{ConvStep}$ under the left and right arguments of application ($r\,s$) and the left and right arguments of iteration ($r\{s\}$), with no reduction permitted under $\lambda$-abstraction. The relation $\mathrm{RedStar}(r, r')$ is the reflexive-transitive closure of $\mathrm{RedStep}$, and $\mathrm{RedSteps}(k, r, r')$ holds for $k \in \mathbb{N}$ when $r$ reduces to $r'$ in exactly $k$ steps of $\mathrm{RedStep}$. A term $r$ is in normal form ($\mathrm{IsNormal}(r)$) if there is no $r'$ with $\mathrm{RedStep}(r, r')$. For a type $\tau$ and term $w$, $\mathrm{HasCanonicalNormalForm}(\tau, w)$ holds according to the top-level constructor of $\tau$:
- for $\tau = U$: $w = \varepsilon$;
- for $\tau = \diamond$: there exists $x \in \mathrm{Var}$ with $x.\mathrm{ty} = \diamond$ and $w = x$;
- for $\tau = L(\rho)$: $\mathrm{IsListTerm}(w)$ holds;
- for $\tau = \rho \otimes \sigma$: there exist $r, s$ such that $w = (\otimes^+_{\rho,\sigma}\,r)\,s$;
- for $\tau = \rho \times \sigma$: there exist a type $\nu$ and terms $r, s, t$ such that $w = ((\times^+_{\rho,\sigma,\nu}\,r)\,s)\,t$;
- for $\tau = \rho + \sigma$: there exists $r$ such that $w = \mathrm{inl}_{\rho,\sigma}\,r$ or $w = \mathrm{inr}_{\rho,\sigma}\,r$;
- for $\tau = \rho \multimap \sigma$: either $w = \lambda x.\, r$ for some $x, r$, or $w = \mathrm{appMany}(c, \mathit{args})$ for some constant $c$ and list of terms $\mathit{args}$ (possibly empty), or $w = r\{s\}$ for some $r, s$.

**Step measures, syntactic measures, and bounded-free-variable reduction (`hashBound`, `theta`, `iterNesting`, `termLength`, `IsIterFree`, `RedStepBounded`).**
For $n \in \mathbb{N}$ and a term $r$, the bounded list length $\#_n(r)$ ($\mathrm{hashBound}(n, r)$) is $k$ if $\mathrm{listEntryCount}(r) = \mathrm{some}(k)$ with $k \le n$, and $n$ otherwise. The step-bounding measure $\vartheta_n(r) \in \mathbb{N}$ ($\mathrm{theta}(n, r)$) is defined recursively on $r$ by:
$$\vartheta_n(x) = 1, \quad \vartheta_n(c) = 1, \quad \vartheta_n(r\,s) = \vartheta_n(r) + \vartheta_n(s), \quad \vartheta_n(\lambda x.\, r) = \vartheta_n(r) + 1, \quad \vartheta_n(r\{s\}) = \vartheta_n(r) + (\#_n(r) + 1)\,\vartheta_n(s).$$
The iteration nesting depth $\mathrm{iterNesting}(r) \in \mathbb{N}$ is $0$ for variables and constants, $\mathrm{iterNesting}(r)$ for $\lambda x.\, r$, $\max(\mathrm{iterNesting}(r), \mathrm{iterNesting}(s))$ for $r\,s$, and $\max(\mathrm{iterNesting}(r), \mathrm{iterNesting}(s) + 1)$ for $r\{s\}$; a term $r$ satisfies $\mathrm{IsIterFree}(r)$ if $\mathrm{iterNesting}(r) = 0$. The syntactic length $\mathrm{termLength}(r) \in \mathbb{N}$ is $1$ for variables and constants, $\mathrm{termLength}(r) + 1$ for $\lambda x.\, r$, and $\mathrm{termLength}(r) + \mathrm{termLength}(s)$ for both $r\,s$ and $r\{s\}$. For $n \in \mathbb{N}$, the bounded one-step reduction relation $r \to_n r'$ ($\mathrm{RedStepBounded}(n, r, r')$) is defined identically to $\mathrm{RedStep}(r, r')$ except that at the base conversion step $s \mapsto s'$, the converted redex subterm $s$ must satisfy $\mathrm{freeVarCount}(s) \le n$.

**Data types, data objects, valid inputs, and polynomial bounds (`IsDataType`, `IsDataObject`, `ValidDataInputs`, `totalTermLength`, `totalFreeVarCount`, `BoundedByPolyOfDegree`).**
A type $\tau \in \mathrm{Ty}$ is a data type ($\mathrm{IsDataType}(\tau)$) if and only if it is built inductively from $U$ using $L(\cdot)$, $\otimes$, and $+$ (excluding $\diamond$, $\multimap$, and $\times$). A term $w$ is a data object of type $\tau$ ($\mathrm{IsDataObject}(\tau, w)$) if $\mathrm{IsDataType}(\tau)$, $\mathrm{HasType}(w, \tau)$, $\mathrm{IsAlmostClosed}(w)$, and $\mathrm{IsNormal}(w)$ all hold. Given a term $r$, a list of types $[\tau_1, \dots, \tau_m]$, and a list of terms $[w_1, \dots, w_m]$, the predicate $\mathrm{ValidDataInputs}(r, [\tau_1, \dots, \tau_m], [w_1, \dots, w_m])$ holds inductively if the two lists have the same length $m$, each $w_i$ satisfies $\mathrm{IsDataObject}(\tau_i, w_i)$, and for each $i \in \{1, \dots, m\}$, $\mathrm{DisjointFV}(((\cdots(r\,w_1)\cdots)\,w_{i-1}), w_i)$ holds (equivalently, the free variables of $r, w_1, \dots, w_m$ are pairwise disjoint). For a list of terms $ws = [w_1, \dots, w_m]$, $\mathrm{totalTermLength}(ws) := \sum_{i=1}^m \mathrm{termLength}(w_i)$ and $\mathrm{totalFreeVarCount}(ws) := \sum_{i=1}^m \mathrm{freeVarCount}(w_i)$ (both equal to $0$ when $ws = []$). Finally, a function $B : \mathbb{N} \to \mathbb{N}$ satisfies $\mathrm{BoundedByPolyOfDegree}(B, d)$ for $d \in \mathbb{N}$ if and only if there exist natural numbers $c_0, c_1 \in \mathbb{N}$ such that for all $n \in \mathbb{N}$,
$$B(n) \le c_0\,(n + 1)^d + c_1.$$

**Predicate symbols and weakly typed argument lists (`PredSym`, `PredSym.arity`, `WeaklyTypedList`).**
A predicate symbol $P \in \mathrm{PredSym}$ is either an equality symbol $=_\rho$ indexed by a type $\rho \in \mathrm{Ty}$, with arity $[ \rho, \rho ]$, or an uninterpreted relation symbol $\mathrm{rel}(\mathrm{id}, \mathit{tys})$ indexed by a natural number identifier $\mathrm{id} \in \mathbb{N}$ and a finite list of argument types $\mathit{tys} \in \mathrm{List}(\mathrm{Ty})$, with arity $\mathit{tys}$. For a list of terms $[r_1, \dots, r_n]$ and a list of types $[\rho_1, \dots, \rho_m]$, the predicate $\mathrm{WeaklyTypedList}([r_1, \dots, r_n], [\rho_1, \dots, \rho_m])$ holds inductively if and only if $n = m$ and $\mathrm{WeaklyTyped}(r_i, \rho_i)$ holds for every $i \in \{1, \dots, n\}$.

**Formulas and logical abbreviations (`Formula`, `eqForm`, `bot`, `neg`, `iffForm`, `impMany`, `allMany`, `exMany`, `allRel`, `lozenge`).**
The inductive type $\mathrm{Formula}$ of formulas is generated by:
- atomic predicate applications $P(r_1, \dots, r_n)$ for $P \in \mathrm{PredSym}$ and a list of terms $[r_1, \dots, r_n]$ (without requiring arity or typing constraints in the raw syntax),
- relativized existence predicates $E_\rho(r)$ for a type $\rho \in \mathrm{Ty}$ and term $r \in \mathrm{Term}$,
- implication $A \to B$, multiplicative conjunction $A \otimes B$, additive conjunction $A \land B$, and disjunction $A \lor B$,
- universal quantification $\forall x.\, A$ and existential quantification $\exists x.\, A$ over a typed term variable $x \in \mathrm{Var}$.

The following formula abbreviations are defined:
- Equality $r =_\rho s := (=_\rho)(r, s)$;
- Falsity $\bot := (\mathrm{tt} =_{\mathrm{B}} \mathrm{ff})$, where $\mathrm{B} = U + U$, $\mathrm{tt} = \mathrm{inl}_{U,U}\,\varepsilon$, and $\mathrm{ff} = \mathrm{inr}_{U,U}\,\varepsilon$;
- Negation $\neg A := A \to \bot$ and bi-implication $A \leftrightarrow B := (A \to B) \land (B \to A)$;
- Iterated implication $\mathrm{impMany}([A_1, \dots, A_n], B) := A_1 \to (\cdots \to (A_n \to B)\cdots)$, iterated universal quantification $\mathrm{allMany}([x_1, \dots, x_n], A) := \forall x_1.\,\cdots\,\forall x_n.\, A$, and iterated existential quantification $\mathrm{exMany}([x_1, \dots, x_n], A) := \exists x_1.\,\cdots\,\exists x_n.\, A$ (each returning the body when $n = 0$);
- Relativized universal quantification $\mathrm{allRel}([x_1, \dots, x_n], B)$, defined recursively as $B$ when $n = 0$ and as $\forall x_1.\, (E_{x_1.\mathrm{ty}}(x_1) \to \mathrm{allRel}([x_2, \dots, x_n], B))$ for $n \ge 1$;
- The constant formula $\lozenge := \exists p_0^\diamond.\, E_\diamond(p_0^\diamond)$, where $p_0^\diamond = (0, \diamond)$.

**Free variables and capture-avoiding substitution on formulas (`freeVarsFormula`, `maxVarIdList`, `maxVarIdFormula`, `renameFreeVarFormula`, `formulaSize`, `renameFreeVarFormula_size`, `substFormula`, `substFormulaMany`).**
For a formula $A$, $\mathrm{freeVarsFormula}(A)$ is the deduplicated list of free term variables occurring in $A$, where $\forall x.\, B$ and $\exists x.\, B$ filter out occurrences equal to $x$. The function $\mathrm{maxVarIdFormula}(A) \in \mathbb{N}$ computes the maximum variable identifier among all free and bound term variables in $A$, and $\mathrm{renameFreeVarFormula}(A, x, y)$ replaces free occurrences of $x$ by $y$ in the terms of $A$ (stopping under $\forall v$ or $\exists v$ when $v = x$), preserving the structural size $\mathrm{formulaSize}(A)$ ($\mathrm{renameFreeVarFormula\_size}$). Capture-avoiding substitution $A[s/x]$ ($\mathrm{substFormula}(A, x, s)$) applies $\mathrm{substTerm}(\cdot, x, s)$ to the terms in atomic formulas and recurses through connectives; at a quantifier $\mathcal{Q} v.\, B$ ($\mathcal{Q} \in \{\forall, \exists\}$), if $v = x$ the formula is unchanged, if $v \neq x$ and $v \in \mathrm{freeVarOccurrences}(s)$ the bound variable $v$ is renamed to $v' := (\max(\mathrm{maxVarIdFormula}(B), \max(\mathrm{maxVarId}(s), x.\mathrm{id})) + 1, v.\mathrm{ty})$ via $\mathrm{renameFreeVarFormula}$ before substituting $s$ for $x$, and otherwise substitution recurses directly into $B$. For a list of pairs $[(x_1, s_1), \dots, (x_n, s_n)]$, $\mathrm{substFormulaMany}(A, [(x_1, s_1), \dots, (x_n, s_n)])$ applies $\mathrm{substFormula}$ sequentially from left to right: $(\cdots(A[s_1/x_1])\cdots)[s_n/x_n]$.

**Computational content, type cleaning, Harrop formulas, and $E$/$\lor$-freeness (`tau`, `cleanTy`, `tauClean`, `IsHarrop`, `IsExistAndDisjFree`).**
For each formula $A$, its potential realizer type $\tau(A) \in \mathrm{Ty}$ ($\mathrm{tau}(A)$) is defined recursively by:
$$\tau(E_\rho(r)) = \rho, \quad \tau(P(r_1, \dots, r_n)) = U, \quad \tau(A \to B) = \tau(A) \multimap \tau(B), \quad \tau(A \otimes B) = \tau(A) \otimes \tau(B),$$
$$\tau(A \land B) = \tau(A) \times \tau(B), \quad \tau(A \lor B) = \tau(A) + \tau(B), \quad \tau(\forall x.\, A) = \tau(A), \quad \tau(\exists x.\, A) = \tau(A).$$
The type-cleaning operation $c(\rho) \in \mathrm{Ty}$ ($\mathrm{cleanTy}(\rho)$) is defined recursively on $\rho$:
- $c(U) = U$, $c(\diamond) = \diamond$, $c(L(\rho)) = L(c(\rho))$, and $c(\rho + \sigma) = c(\rho) + c(\sigma)$;
- for $\rho \multimap \sigma$: if $c(\sigma) = U$ then $U$; else if $c(\rho) = U$ then $c(\sigma)$; else $c(\rho) \multimap c(\sigma)$;
- for $\rho \star \sigma$ with $\star \in \{\otimes, \times\}$: if $c(\sigma) = U$ then $c(\rho)$; else if $c(\rho) = U$ then $c(\sigma)$; else $c(\rho) \star c(\sigma)$.

The cleaned realizer type of $A$ is $\tau^c(A) := c(\tau(A))$ ($\mathrm{tauClean}(A)$). A formula $A$ is Harrop / computationally irrelevant ($\mathrm{IsHarrop}(A)$) if and only if $\tau^c(A) = U$. A formula $A$ satisfies $\mathrm{IsExistAndDisjFree}(A)$ if and only if it is built from atomic predicate formulas $P(r_1, \dots, r_n)$ using only $\to$, $\otimes$, $\land$, $\forall$, and $\exists$ (containing neither $E_\rho(r)$ nor $\lor$).

**Assumption variables, contexts, and axiom conversion equations (`AssumpVar`, `ProofContext`, `AxiomConvEq`).**
An assumption variable $u \in \mathrm{AssumpVar}$ is a pair $(\mathrm{id}, \mathrm{formula})$ with $\mathrm{id} \in \mathbb{N}$ and $\mathrm{formula} \in \mathrm{Formula}$, and a proof context $\Delta, \Gamma \in \mathrm{ProofContext}$ is a finite list of assumption variables. **Proof terms and two-zone natural deduction (`ProofTerm`, `substAssumpProof`, `boundAssumpVars`, `allAssumpVars`, `DisjointProofCtx`, `CtxIdsUnique`, `IsDisjointCtxUnion`, `VarCond`, `indStepFormula`, `Derives`, `Provable`, `ClosedProvable`).**
Raw proof terms $M, N \in \mathrm{ProofTerm}$ are generated by assumption variables $u$, core axioms $c$, assumption abstractions $\lambda u.\, M$, term abstractions $\lambda x.\, M$, proof applications $M\,N$, term applications $M\,r$, and list inductions $N\{M\}$. The operation $\mathrm{substAssumpProof}(M, u, v)$ replaces free occurrences of assumption variable $u$ with $v$ in $M$ (stopping under $\lambda w$ if $w = u$). For a proof term $M$, $\mathrm{boundAssumpVars}(M)$ lists all assumption variables $w$ occurring in $\lambda w$ binders inside $M$, and $\mathrm{allAssumpVars}(M)$ lists all assumption variables occurring either as $\mathrm{assump}(w)$ leaves or as $\lambda w$ binders in $M$. Two proof contexts $\Delta, \Gamma$ are disjoint ($\mathrm{DisjointProofCtx}(\Delta, \Gamma)$) if $u.\mathrm{id} \neq v.\mathrm{id}$ for all $u \in \Delta$ and $v \in \Gamma$. A context $\Theta$ satisfies $\mathrm{CtxIdsUnique}(\Theta)$ if any $u, v \in \Theta$ with $u.\mathrm{id} = v.\mathrm{id}$ satisfy $u = v$. The relation $\mathrm{IsDisjointCtxUnion}(\Delta, \Gamma, \Theta)$ holds if $\mathrm{DisjointProofCtx}(\Delta, \Gamma)$, $\mathrm{CtxIdsUnique}(\Theta)$, and every $u \in \mathrm{AssumpVar}$ belongs to $\Theta$ if and only if $u \in \Delta$ or $u \in \Gamma$. The derivability judgment $\Delta \mid \Gamma \vdash M : A$ ($\mathrm{Derives}(\Delta, \Gamma, M, A)$, with passive context $\Delta$ and active context $\Gamma$) is inductively defined by nine rules:
1. **Assumption:** If $\mathrm{DisjointProofCtx}(\Delta, \Gamma')$ and $\mathrm{IsDisjointCtxUnion}(\Gamma, [u], \Gamma')$, then $\Delta \mid \Gamma' \vdash u : u.\mathrm{formula}$.
2. **Axiom:** If $\mathrm{DisjointProofCtx}(\Delta, \Gamma)$ and $c.\mathrm{IsValid}$, then $\Delta \mid \Gamma \vdash c : c.\mathrm{formula}$.
3. **$\to$-Introduction:** If $\mathrm{IsDisjointCtxUnion}(\Gamma, [u], \Gamma')$ and $\Delta \mid \Gamma' \vdash M : B$, then $\Delta \mid \Gamma \vdash \lambda u.\, M : u.\mathrm{formula} \to B$.
4. **$\to$-Elimination:** If $\mathrm{IsDisjointCtxUnion}(\Gamma_1, \Gamma_2, \Gamma)$, $\Delta \mid \Gamma_1 \vdash M : A \to B$, and $\Delta \mid \Gamma_2 \vdash N : A$, then $\Delta \mid \Gamma \vdash M\,N : B$.
5. **$\forall$-Introduction:** If $\Delta \mid \Gamma \vdash M : A$ and $x \notin \mathrm{freeVarsFormula}(u.\mathrm{formula})$ for all $u \in \Delta \cup \Gamma$ ($\mathrm{VarCond}(x, \Delta, \Gamma)$), then $\Delta \mid \Gamma \vdash \lambda x.\, M : \forall x.\, A$.
6. **$\forall$-Elimination:** If $\Delta \mid \Gamma \vdash M : \forall x.\, A$ and $\mathrm{WeaklyTyped}(r, x.\mathrm{ty})$, then $\Delta \mid \Gamma \vdash M\,r : A[r/x]$.
7. **Passification:** If $\mathrm{IsDisjointCtxUnion}([u], \Gamma, \Gamma')$, $\mathrm{IsDisjointCtxUnion}(\Delta, [u], \Delta')$, $\mathrm{IsHarrop}(A)$, and $\Delta \mid \Gamma' \vdash M : A$, then $\Delta' \mid \Gamma \vdash M : A$.
8. **Contraction:** If $u.\mathrm{formula} = v.\mathrm{formula}$, $v \notin \mathrm{boundAssumpVars}(M)$, $\mathrm{IsDisjointCtxUnion}([u], \Delta, \Delta')$, $\mathrm{IsDisjointCtxUnion}([v], \Gamma, \Gamma')$, and $\Delta' \mid \Gamma' \vdash M : B$, then $\Delta \mid \Gamma' \vdash \mathrm{substAssumpProof}(M, u, v) : B$.
9. **$L(\tau)$-Induction:** If $p.\mathrm{ty} = \diamond$, $x.\mathrm{ty} = \tau$, $l.\mathrm{ty} = L(\tau)$, $p, x, l$ are pairwise distinct, $p, x \notin \mathrm{freeVarsFormula}(A)$, $\mathrm{WeaklyTyped}(t, L(\tau))$, $\Delta \mid \Gamma \vdash N : E_{L(\tau)}(t)$, and $\Delta \mid [] \vdash M : \forall p.\,\forall x.\,\forall l.\, (E_\diamond(p) \to (E_\tau(x) \to (A \to A[(((\mathrm{cons}_\tau\,p)\,x)\,l)/l])))$, then $\Delta \mid \Gamma \vdash N\{M\} : A[\mathrm{nil}_\tau/l] \to A[t/l]$.

Finally, $\mathrm{Provable}(\Delta, \Gamma, A)$ holds if there exists $M \in \mathrm{ProofTerm}$ such that $\Delta \mid \Gamma \vdash M : A$, and $\mathrm{ClosedProvable}(A)$ holds if $\mathrm{Provable}([], [], A)$.
