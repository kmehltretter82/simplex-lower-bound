SCRIPT CAVEATS

scripts/stage_drafts.py can be reused for body construction and offline validation,
but its normal --write path is not a complete existing-proposal replacement:
- It creates a new proposal unless state.proposal_id is pre-seeded.
- Its API allowlist excludes DELETE.
- Its transport unconditionally JSON-parses responses, so204 deletion fails.
- It does not remove old reference items or old milestone roles.
- It finally sends order containing only packet item IDs, which is problematic
  while old items remain if the server enforces the full-list rule.
- Its library check omits include_deprecated, so supplement the name preflight.
- Its no-op decisions use local stored hashes without verifying all current remote
  content, so the final readback equality check is still essential.
Prefer a narrowly scoped repair driver or explicit sequential requests to P,
retaining the existing secure credential transport and ambiguous-write journal.
